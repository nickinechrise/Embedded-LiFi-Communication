# Secure Underwater Data & Audio Transmission System (Li-Fi Prototype)

An embedded hardware prototype designed for wireless optical communication using modulated LEDs and photodiode detection for underwater/marine applications.

## 📌 Features
- **Optical Wireless Communication:** Transmits data via light intensity modulation (OOK - On-Off Keying).
- **Target Performance:** Achieved low-latency data transmission across a tested range of **1.5 meters**.
- **Microcontroller Integration:** Compatible with Arduino / ESP32 hardware frameworks.

## 🛠️ Hardware & Tech Stack
- **Language:** Embedded C / C++
- **Microcontrollers:** Arduino / ESP32
- **Components:** High-power Transmitter LED, Photodiode Receiver Array, Signal Amplifiers
- **Protocols/Methods:** On-Off Keying (OOK), Analog/Digital Signal Processing

## 🚀 How It Works
1. Data/Audio signals are encoded into digital pulses.
2. The Transmitter modulates the light intensity at high frequencies.
3. The Photodiode Receiver detects light pulses, converts them into analog electrical signals, and decodes the message.
